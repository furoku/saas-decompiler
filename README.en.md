# SaaS Decompiler — English

A 40-prompt toolkit for reconstructing SaaS product structure from observable evidence.

**Core method:** Pixel → Component → Screen → Flow → Feature → Data → Rule → System → Business

## Prompt library

[Open the English prompts](prompts/en.md)

## What you can analyze

Product strategy, UI/UX, design systems, frontend architecture, data models, user flows, state machines, business logic, authentication, permissions, billing, onboarding, AI features, APIs, integrations, notifications, admin tooling, security, growth, MVP scope, and implementation specs.

## Rule of evidence

Always separate **Observation** (directly visible facts), **Inference** (reasonable conclusions), and **Speculation** (unsupported hypotheses).
