# Security Policy

This repository contains prompts and documentation only. It has no runtime service, package dependency, authentication system, or production deployment.

## Reporting a security issue

If you believe repository content could expose credentials, private data, or another security-sensitive issue, please avoid posting secrets or personal data in a public issue. Contact the repository owner through an appropriate private channel instead.

## Scope

Please do not use this project to bypass access controls, obtain private source code, extract credentials, discover secrets, or access data you are not authorized to access.
