# SaaS Decompiler — 繁體中文

從截圖、公開頁面、可實際操作的產品畫面與公開文件等**可觀察資訊**，反推出 SaaS 結構並整理成可獨立實作規格的 40 組提示詞。

**核心框架：** Pixel → Component → Screen → Flow → Feature → Data → Rule → System → Business

## 提示詞集

[開啟繁體中文 40 組提示詞](prompts/zh-TW.md)

## 分析範圍

產品策略、UI/UX、設計系統、前端架構、資料模型、使用者流程、狀態機、商業邏輯、驗證與權限、計費、Onboarding、AI SaaS、API、整合、通知、管理後台、安全性、Growth、MVP、實作規格等。

## 最重要規則

永遠分開 **Observation（可直接確認的事實） / Inference（合理推論） / Speculation（證據不足的假設）**。
