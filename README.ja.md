# SaaS Decompiler — 日本語

スクリーンショット、公開ページ、実際に操作できる画面、公開ドキュメントなどの**観察可能な情報**から、SaaSの構造を独立実装できる粒度まで逆算する40種類のプロンプト集です。

**基本フレーム:** Pixel → Component → Screen → Flow → Feature → Data → Rule → System → Business

## プロンプト集

[日本語版40プロンプトを開く](prompts/ja.md)

## 分析できるもの

プロダクト戦略、UI/UX、デザインシステム、フロントエンド構造、データモデル、ユーザーフロー、状態遷移、ビジネスロジック、認証・権限、課金、オンボーディング、AI SaaS、API、外部連携、通知、管理画面、セキュリティ、グロース、MVP、実装仕様など。

## 最重要ルール

**Observation（観察事実） / Inference（合理的な推論） / Speculation（証拠不足の仮説）** を必ず分離します。

ここでいう「逆コンパイル」は非公開コードや秘密情報の取得ではなく、観察できるプロダクト体験から設計構造を読み解くことを意味します。
