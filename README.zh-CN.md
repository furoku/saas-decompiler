# SaaS Decompiler — 简体中文

从截图、公开页面、可实际操作的产品界面与公开文档等**可观察信息**，反推出 SaaS 结构并整理成可独立实现规格的 40 组提示词。

**核心框架：** Pixel → Component → Screen → Flow → Feature → Data → Rule → System → Business

## 提示词集

[打开简体中文 40 组提示词](prompts/zh-CN.md)

## 分析范围

产品策略、UI/UX、设计系统、前端架构、数据模型、用户流程、状态机、业务逻辑、认证与权限、计费、Onboarding、AI SaaS、API、集成、通知、管理后台、安全性、Growth、MVP、实现规格等。

## 最重要规则

始终分开 **Observation（可直接确认的事实） / Inference（合理推断） / Speculation（证据不足的假设）**。
